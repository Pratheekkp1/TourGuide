# MLH Prize Reference

## Philosophy
Build the best, most usable project for the theme. When a feature calls for a tool,
check if a prize tool is the natural best fit — if so, use it. Never force a prize
tool where it hurts the project quality or usability.

---

## Tools, Access & What They're Good For

### Gemini API — Google Swag Kits
**Best for:** Multimodal AI (vision + text), long context windows, second AI brain
**Use when:** Feature needs image/video understanding, or a different model than Claude
**How to access:**
- Students: claim Google AI Pro free for 1 year → mlh.link/gemini-hackathon-hub
- Get $10/month free credits via Google Program Benefits
- Non-students: $300 in free credits with new account
- API key: aistudio.google.com
**Prize rule:** Must meaningfully use the Gemini API

---

### ElevenLabs — Wireless Earbuds
**Best for:** Realistic AI voice, TTS, conversational voice agents, expressive audio
**Use when:** Feature has any audio output, narration, or voice interaction
**How to access:**
- Register for Bitcamp first at mlh.io/events
- Week of event: MLH emails you a promo code for a **free 3-month ElevenLabs subscription**
- Redeem via the link in that email
**Prize rule:** Must use ElevenLabs SDK/API for audio generation

---

### Auth0 — Wireless Headphones (x2 prizes, 1 integration)
**Best for:** User auth, social login, MFA, passwordless — AND securing AI agents
**Use when:** App needs user accounts or AI agents acting on behalf of users
**How to access:**
- Free signup at auth0.com — no credit card, 7,000 MAU free
- Covers BOTH "Best Use of Auth0" AND "Best Use of Auth0 AI Agents" prizes
**Prize rules:**
- Auth0 prize: use Auth0 APIs for authentication
- Auth0 AI Agents prize: use Auth0 specifically to secure AI agent workflows

---

### MongoDB Atlas — M5Stack IoT Kit
**Best for:** Flexible document DB, vector search, unstructured/variable data
**Use when:** App needs a database (especially with AI embeddings or variable schemas)
**How to access:**
- Free forever tier at mongodb.com/atlas (no credit card)
- OR $50 credits via GitHub Student Developer Pack
**Prize rule:** Must use MongoDB Atlas (cloud-hosted, not local MongoDB)

---

### Cloudflare — Arduino Kit
**Best for:** Edge deployment, serverless backend, Workers AI (run LLMs/image/voice in cloud)
**Use when:** Deploying the app or running AI inference serverlessly
**How to access:**
- Free account at cloudflare.com
- Workers AI included in free tier — run ML models on Cloudflare's global network
- Use C3 CLI (`npm create cloudflare`) to scaffold instantly
- Multi-modal AI Playground to test models in browser
**Prize rule:** Must build an AI application using Cloudflare services (not just DNS/CDN)

---

### Snowflake — Raspberry Pi 4
**Best for:** RAG via REST API, LLM queries, SQL over large datasets, Cortex AI
**Use when:** Feature needs retrieval-augmented generation or data analysis
**How to access:**
- 120-day free student trial at mlh.link/snowflake-signup
- Cortex AI Studio for AI features: mlh.link/snowflake-cortex-ai-studio
- Example chat app repo available
**Prize rule:** Must use Snowflake REST API or Cortex AI meaningfully

---

### Reach Capital AI — Logitech Webcam + Investor Meeting

**Use when:** Project helps workers in healthcare, construction, retail, logistics, education
**How to access:** No specific SDK — build AI for frontline workers, submit via Airtable form
**Prize rule:** Must be AI-powered AND genuinely target the frontline/labor economy
**Note:** Investor meeting with Reach Capital is the highest-value non-hardware prize
