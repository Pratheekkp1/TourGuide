# TourGuide 🧭

**Point your phone at any street and get told how to navigate it like a local.**

TourGuide is a real-time AI travel companion built at **Bitcamp 2026** (University of Maryland's hackathon, Machine Learning track). It runs computer vision on the live camera feed to understand the scene in front of you, then layers on culturally aware, spoken guidance: what kind of place you're in, what people are doing, the local etiquette, which tourist scams to watch for, and how to get where you're going.

## Features

| | |
|---|---|
| 🎥 **Live scene understanding** | CLIP zero-shot classification over 32 hand-written scene descriptions, plus MediaPipe face detection and activity classification, with temporal smoothing (3-of-5 frame hysteresis) to stop label flicker |
| 🔍 **Drag-to-identify** | Select any region of the camera feed; the crop goes to Gemini Vision with location context for a structured breakdown of what you're looking at |
| 🗣️ **Spoken guidance** | Short, friend-style advice generated by Gemini and read aloud via ElevenLabs, falling back to the browser's speech synthesis |
| 🏙️ **City intel** | Common local scams, local-vs-tourist price benchmarks, etiquette and phrases for the city you're in |
| 🗺️ **Map & navigation** | Nearby points of interest from OpenStreetMap, turn-by-turn routes via OSRM, places along your route, and a live navigation overlay |
| 🌐 **Multilingual** | AI guidance in 20 languages (Arabic, Hindi, Japanese, Swahili and more); UI translated into 10 |

## Architecture

```
┌──────────────────────────── React + Vite (mobile web) ───────────────────────────┐
│  CameraView ── frames every ~500ms ──►  /api/detect   (fast face boxes)          │
│             ── frames every few s  ──►  /api/analyze  (scene + people + activity)│
│  TapIdentify ── cropped region ────►  /api/identify   (Gemini Vision)            │
│  MapView ─────────────────────────►  /api/nearby, /api/route, /api/place-info    │
│  GuidanceCard / speak() ──────────►  /api/guidance, /api/tts                     │
└──────────────────────────────────────────────────────────────────────────────────┘
                                   │
┌─────────────────────────────── FastAPI backend ──────────────────────────────────┐
│  models/scene_classifier.py   CLIP ViT-B/32 zero-shot scene classification       │
│  models/people_detector.py    MediaPipe detection + custom NMS                   │
│  models/activity_classifier   reuses the loaded CLIP weights (no extra memory)   │
│  routes/*                     Gemini, ElevenLabs, OSM Overpass and OSRM          │
└──────────────────────────────────────────────────────────────────────────────────┘
```

Third-party API keys (Gemini, ElevenLabs) stay on the server. The browser only talks to the TourGuide API.

## Tech stack

**Frontend:** React 18, Vite, Tailwind CSS, Leaflet / Google Maps
**Backend:** Python, FastAPI, PyTorch, Hugging Face Transformers (CLIP), MediaPipe
**AI / APIs:** Google Gemini 2.5 Flash, ElevenLabs TTS, OpenStreetMap Overpass, OSRM

## Running locally

```bash
# Backend
cd backend
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # add GEMINI_API_KEY and ELEVENLABS_API_KEY
uvicorn main:app --reload --port 8000

# Frontend (new terminal)
cd frontend
npm install
cp .env.example .env          # add VITE_GOOGLE_MAPS_API_KEY
npm run dev                   # http://localhost:5173
```

Camera access needs HTTPS or `localhost`. To try it on a phone, tunnel the dev server (e.g. `ngrok http 5173`).

## What I learned

- **Making zero-shot CLIP reliable on a live feed.** Writing detailed visual descriptions instead of single-word labels, adding a confidence floor and smoothing predictions over frames made the biggest difference.
- **Splitting fast and slow inference paths.** Cheap face detection updates bounding boxes at roughly 2 fps while full scene analysis runs less often, which keeps the UI responsive.
- **Sharing model weights across tasks** (scene + activity classification) to fit on a laptop-class backend.
